# バク転メーカー

写真を1枚えらぶだけで、写っている人がバク転する動画ができる無料ツールです。
スマホでもパソコンでも、ブラウザだけで使えます。登録もいりません。

**▶ 使ってみる：https://hibiki-no-ie.github.io/bakuten-maker/**

## できること

- 写真から人だけを自動で切り抜き
- 「くるっと宙返り」「正面からバク転」の2種類
- 1〜3回転
- 最後に好きな文字を表示（例：決まった！）
- 効果音つきの縦長動画（ショート動画サイズ）で保存

写真はスマホやパソコンの中だけで処理し、どこにも送りません。
他人の写真を使うときは、本人の了解をとってからにしましょう。
